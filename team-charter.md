## Communication

Communication will be done through a text group chat.

We will notify each other through the group chat when something is merged, broken, or requires attention.

Team members should respond to important team messages as soon as reasonably possible.

When a teammate is blocked on a task, the team will work to resolve the issue within two days at the latest.

## GitHub Workflow

All work should be completed on separate branches.

Changes to the main branch should be submitted through Pull Requests.

At least one team member must review and approve a Pull Request before it is merged into main.

Team members should avoid making completed project changes directly on the main branch.

## Meetings

The team will meet during scheduled class and lab time.

Additional communication and coordination will take place through the team group chat as needed.
